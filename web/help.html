About WeatherBrief

WeatherBrief is an exploratory weather briefing tool for general aviation pilots. It fetches forecasts from multiple numerical weather prediction (NWP) models and runs analysis routines to produce advisories, cross-sections, soundings, and a synthesized overview of conditions along your planned route.

WeatherBrief is designed for multi-model comparison — instead of relying on a single forecast, it shows you where models agree and where they diverge, so you can gauge confidence in the forecast.

Getting Started

  1. Create a flight on the Flights page by entering your waypoints (ICAO airport codes), date, time, altitude, and ceiling.
  2. Open the briefing by clicking the flight card. WeatherBrief will fetch forecast data from each enabled model, run thermodynamic analysis, compute advisories, and generate a synopsis.
  3. Refresh the briefing at any time to pull the latest available forecasts. Each refresh creates a new snapshot you can compare via the history dropdown.
You can configure which NWP models to use and tune advisory thresholds in Settings.

The Briefing Page

The briefing is organized into collapsible sections. Here's what each one shows:

Route Advisories

Advisories flag hazardous conditions along your route. Each advisory is rated GREEN, AMBER, or RED based on configurable thresholds. Advisories are computed per-model, so you can see whether multiple models agree on a hazard or if only one flags it.

Categories include icing, turbulence, cloud/visibility, convective activity, and airport conditions.

Synopsis

An LLM-generated plain-language overview of the weather situation along your route. It summarizes the key findings from the numerical analysis in a concise narrative.

GRAMET Cross-Section

A vertical cross-section chart from autorouter.aero showing cloud, wind, temperature, and turbulence along your route. This requires Autorouter credentials configured in Settings.

Cross-Section Visualization

An interactive canvas-based vertical cross-section built from the NWP model data. It renders multiple layers (clouds, icing, wind, humidity, etc.) that you can toggle on and off using the control panel.

  • Use the model selector to switch between forecast models.
  • Hover over the canvas to see values at a specific point.
  • Click to pin the readout at a location.
  • Toggle individual layers to isolate specific phenomena.

Skew-T Soundings

Skew-T / Log-P diagrams for each waypoint, generated from the model data. These show the vertical temperature and dewpoint profiles — essential for assessing stability, cloud bases, freezing levels, and convective potential. Use the model dropdown to compare soundings across models.

Route Profile

A slider that lets you move along the route and view a Skew-T sounding and key metrics at any interpolated point, not just the waypoints. Useful for examining conditions between airports.

Sounding Analysis

A table of thermodynamic indices derived from each sounding: CAPE, CIN, lifted index, freezing level, cloud layers, icing zones, and more. Values are shown per-model so you can spot where models agree or diverge.

Model Comparison

A divergence analysis that scores how well the models agree on key variables at each waypoint. High agreement gives confidence in the forecast; poor agreement signals uncertainty.

Info Buttons

Throughout the briefing you'll see small (i) buttons next to metrics and layer names. Clicking one opens a popup explaining what the metric measures, what the thresholds mean, and how to interpret the values in a flying context.

Settings

  • Forecast Models — choose which NWP models are fetched on each briefing refresh.
  • Advisory Parameters — enable/disable individual advisories and fine-tune their thresholds (e.g. icing temperature band, crosswind limits).
  • Flight Defaults — set default cruise altitude and ceiling for new flights.
  • Autorouter Credentials — enter your autorouter.aero username and password to enable GRAMET charts. Credentials are encrypted at rest.
