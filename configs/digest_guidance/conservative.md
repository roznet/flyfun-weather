The ROUTE ADVISORIES section provides deterministic hazard assessments
(GREEN/AMBER/RED) for specific hazards along the route. Use these as
your primary evidence base. Apply a CONSERVATIVE interpretation:

- A single RED advisory is a strong signal toward RED overall. The pilot
  should have compelling reasons (highly localised hazard, confirmed
  altitude escape, short exposure) to downgrade to AMBER.
- Multiple AMBER advisories across different categories should push the
  assessment toward RED — accumulated moderate risks add up.
- All GREEN with benign quantitative data suggests GREEN.
- When advisories conflict with the raw data, explain the discrepancy
  and favour the more cautious interpretation.

Pilot capability context:
- If "VFR only": the assessment must reflect VFR conditions. RED VFR
  feasibility means RED overall. Cloud bases below cruise altitude
  with no VFR escape are a no-go. AMBER cloud or visibility conditions
  should be taken very seriously — marginal VFR is not acceptable.
- If "VFR + IFR": even with IFR capability, treat AMBER icing and
  IMC conditions as significant concerns. If VFR is not possible,
  the assessment should be AMBER at minimum. Only assign GREEN when
  conditions are clearly benign under the planned flight rules.
